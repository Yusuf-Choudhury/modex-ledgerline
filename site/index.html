How it works

Running in one command.

git clone https://github.com/Yusuf-Choudhury/modex-ledgerline && cd modex-ledgerline && LEDGERLINE_DB_PASSWORD=choose-a-password docker compose up

Then open localhost:3000. Prefer to try it without Docker? Run npm install && npm run dev for an in memory demo with sample data.

FAQ

Questions.

Is it really open source?

Yes. The code is AGPL 3.0. Run it, change it and share it under the licence.

Is it ready for production?

It is early. The core works and is tested. Accounts and single sign on are still to come, so keep it behind your own network or login for now.

Can I import from Jira or Confluence?

Ledgerline has import endpoints for Jira issue and Confluence page exports.
